# Esperanto (`eo`)

Deinflection rules, text processors and scanning settings for Esperanto.
Lookups start at the hovered word and try only prefixes that end at a word
boundary (`word` / `word` / `spaces`, docs/languages.md 14.1).

Status: the pack's own rules, written before Yomitan's Esperanto rules were
read (docs/languages.md 14 step 2). Yomitan's rules, the corpus and the
measurements follow.

## Sources and licences

- `sources/own.json` and every rule of `transforms.json` with source `own`:
  written for this pack (GPL-3.0-or-later), generated by
  `sources/build-own.mjs` from the standard description of Esperanto
  grammar (the *Fundamento de Esperanto*, 1905; Kalocsay and Waringhien,
  *Plena Analiza Gramatiko de Esperanto*; Wiktionary's Esperanto inflection
  tables). No text or table is copied from them.
- `language.json`, `sources/lookup-batch.cpp`, `sources/make-hovers.py` and
  `sources/measure-derivation.py`: written for this pack (GPL-3.0-or-later).
