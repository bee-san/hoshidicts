# Italian (`it`)

Deinflection rules, text processors and scanning settings for Italian.

## Sources and licences

- `sources/own.json` and every rule of `transforms.json` with source `own`:
  written for this pack (GPL-3.0-or-later), generated by
  `sources/build-own.mjs` from paradigm tables of Italian inflection written
  from the standard description of the language. No text or table is copied
  from a source.

## Rule provenance

All rules are `own` at this commit; Yomitan has no Italian deinflection rules.
