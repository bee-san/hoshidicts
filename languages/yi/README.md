# Yiddish (`yi`)

Deinflection rules, text processors and scanning settings for Yiddish in
YIVO spelling, the spelling of the recommended dictionary (wty-yi-en).
Work in progress: this commit has the pack's own rules, written before
Yomitan's Yiddish rules were read (docs/languages.md, section 14 step 2).

## Sources and licences

- `sources/own-rules.mjs`, `sources/own.json` and `language.json`: written
  for this pack (GPL-3.0-or-later) from the standard description of YIVO
  Yiddish morphology and spelling.
