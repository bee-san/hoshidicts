# Ukrainian (`uk`)

Deinflection rules, text processors and scanning settings for Ukrainian.
Lookups start at the hovered word and try only prefixes that end at a word
boundary (`word` / `word` / `spaces`, docs/languages.md 14.1). The
apostrophe is part of a word (`wordInternal`: ', ’, ʼ, ‘, `, ´), so м’ясо and
п’ять are looked up whole; hyphens separate words, so будь-якого is looked
up whole and from якого.

The processors are Yomitan's: decapitalisation, capitalisation of the first
letter, stress marks removed (the acute, and here also the grave), and the
apostrophe variants (', ’ and ʼ tried for any of the six). One processor is
this pack's own: `alternateInitialUV` tries a word's initial у before a
consonant as в and the other way round (учитель, вчитель; Вкраїні, Україні),
the alternation the spelling rules allow and texts use. No processor or
transform is optional, so every test file runs the same with every option on
and with the pack's defaults.

## Rule provenance

the union `tools/merge-transforms.mjs` makes of `sources/own.json` and
`sources/yomitan.json`, with the own transforms first, every Yomitan rule
limited to one word (`stemCharacters` `{stem}`, as the own rules are: Yomitan's
rules have no stem constraint and read на столі as на стіл), and the

- 113 transforms: 79 own, 34 Yomitan (Yomitan's 35 without `superlative`,
  whose two `най-` prefix rules are left out; the own superlative rules go
  to the positive in one step).
- 8,565 rules: 4,686 own, 490 both, 3,389 Yomitan. By type: 5,963 suffix,
  2,533 whole-word and 69 circumfix (prefix and suffix) rules, written as 657
  JSON rules because rules that differ only in their affixes are one cross

  map to suffix rules with `stemChange` (the о/е → і alternation),
  `stemEndsWith` (fleeting vowels), `stemContains` (the zero ending) and

  `build-own.mjs` gives them (rules matching at one place apply in file
  order, which decides ties, section 9.6).
