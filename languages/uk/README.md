# Ukrainian (`uk`)

Deinflection rules, text processors and scanning settings for Ukrainian.
Lookups start at the hovered word and try only prefixes that end at a word
boundary (`word` / `word` / `spaces`, docs/languages.md 14.1). The apostrophe
(’, ʼ, ') is part of a word (м’ясо, п’ять); hyphens separate words, so
будь-якого is looked up whole and from якого.
